# 100万円ポートフォリオ・チャレンジ

金融教育用のチーム対抗型株式投資シミュレーションゲームです。

## ゲームを開く

https://ooharahiroki1-jpg.github.io/portfolio-challenge/

## 別のPCでローカル起動

```bash
git clone https://github.com/ooharahiroki1-jpg/portfolio-challenge.git
cd portfolio-challenge
corepack enable
pnpm install
pnpm dev
```

起動後、ブラウザで `http://127.0.0.1:5173/` を開きます。

## 品質確認

```bash
pnpm lint
pnpm test
pnpm build
```
